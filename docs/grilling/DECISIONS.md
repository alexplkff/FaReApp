# Решения интервью

Все решения ниже имеют статус `accepted` на основании явных ответов пользователя.

| ID | Решение |
|---|---|
| D-001 | Разделить «Убрать из библиотеки» и «Удалить книгу с устройства»; исходный файл не затрагивать. |
| D-002 | Одинаковое содержимое не дублировать; изменённое содержимое считать новой книгой. |
| D-003 | Поддерживать постраничный и непрерывный режимы; постраничный основной. |
| D-004 | Для изменённой версии не переносить прогресс и закладки. |
| D-005 | После последнего слова показать состояние «прочитано» и варианты возврата/старта сначала. |
| D-006 | Статические изображения показывать только в обычном режиме. |
| D-007 | Поддерживать `.fb2` и `.fb2.zip`, включая изображения архивированной книги. |
| D-008 | WPM задаёт базовый интервал; пунктуационные паузы добавляются. |
| D-009 | MVP полностью offline-first. |
| D-010 | Переключатель оформления книги/приложения; скорочтение использует оформление приложения. |
| D-011 | Внутренние ссылки и сноски поддерживаются, внешние ссылки — нет. |
| D-012 | При отсутствии TOC строить его по структуре, иначе читать без TOC. |
| D-013 | Прогресс сохранять при паузе и штатном выходе. |
| D-014 | Формат определять по содержимому, а не только по расширению. |
| D-015 | При переключении режимов сохранять близкую позицию по тексту. |
